# Ethiopian Plant Species Catalog 🌱

## About This Project

This project is a growing catalog of plant species found in
Ethiopia.

The purpose is to organize basic scientific information about
plants in a simple and accessible format.

## Information Included

Each plant entry may include:

- Scientific name
- Common name
- Plant family
- Growth form
- Habitat
- Geographic distribution
- Uses
- Economic importance
- Conservation status
- References

## Example Species

### Coffee

**Scientific name:** *Coffea arabica*

**Family:** Rubiaceae

**Growth form:** Shrub or small tree

**Importance:** Coffee is an important agricultural and
economic crop in Ethiopia.
